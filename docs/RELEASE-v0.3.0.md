# Yasin Chess v0.3.0

## Android standalone release

- Capacitor v8 Android runtime
- Offline-first bundled application
- Android lifecycle/back navigation integration
- Safe-area and edge-to-edge support
- Responsive portrait/landscape behavior
- Native haptics
- Native PGN share
- Android debug/release/AAB build workflows
- Emulator install and offline smoke workflows
- Security, persistence, regression, and performance gates

## Release requirement

Create the `v0.3.0` Git tag from the final main commit after the final release issue is merged. A signed production APK requires the external signing secrets described in `docs/ANDROID-SIGNING.md`.
